# 熊萌圣诞冰雪艺术馆 3D 互动世界 (Xiongmeng Art Museum Wonderland)

基于 **Three.js (v0.168.0)** 单文件构建的圣诞雪夜 3D 沉浸式交互世界，集成了两层+屋顶露台的熊萌艺术馆、大型圣诞游乐园、哥特婚礼大教堂、百老汇圣诞大剧院、外环观光小火车、高空弹射跳伞及全城外围街景。

- **线上预览**: https://preview.ai10088.com/alex-garage/
- **主入口源码**: [xiongmeng-art-museum.html](./xiongmeng-art-museum.html)
- **详细交接文档**: [HANDOFF.md](./HANDOFF.md)

## 核心特性
- **双模式漫游**：支持沙盘鸟瞰（`WASD` 平移 / 鼠标拖拽旋转）与第一人称步行模式（`WASD` 走、`Shift` 奔跑、进出艺术馆 1F/2F/屋顶、教堂红毯观礼）。
- **可交互游乐设施**：
  - 敞篷观景摩天轮、旋转木马、海盗船、高空飞索、碰碰车、圣诞飞天雪橇（坐在礼物堆俯瞰全城）、圣诞巡逻直升机
  - **高空弹射跳伞塔 (`SKY LAUNCH`)**：弹射冲上 `~51m` 高空，自动开伞后 `WASD` 全程可控滑翔降落
  - **外环露天观光小火车**：`3` 个站点（东街雪原站 / 游乐园南站 / 西街市集站），点击或按 `E` 上下车
- **圣诞氛围与互动玩法**：游乐园上空密集烟花秀、盲盒礼物山（可拆出 10 种 3D 礼物摆入艺术馆展出）、游客留言信箱（接阿里云 SQLite 后端）、全图冬夜空气透视光雾、外围 `InstancedMesh` 车流与行人。
